Kodiak-v0.4-1B · running locally

Accept when confident.
Escalate when unsure.

Paste a question and two answers. Kodiak decides which is better in a few dozen milliseconds, and says so only when it's sure. Everything else goes to a person or an LLM. Every pair is judged in both orders, so a preference for the first or second slot can't decide the verdict.
